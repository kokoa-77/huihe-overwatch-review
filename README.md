# 回合 · 守望先锋 2 训练记录与复盘

回合是一个开源的 OW2 个人训练记录网站。它把每场对局的基本资料、结算数据、回放时间点、阵亡原因和下一局动作放在一起，方便玩家记录、筛选和回看自己的训练过程。

当前版本是可交互的本地演示。无需安装依赖，也不需要账号；演示记录保存在当前浏览器，不会上传到服务器。示例对局为虚构数据。

## 开始体验

直接用浏览器打开 `index.html`，或从仓库目录运行一个本地静态服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。项目使用原生 HTML、CSS 和 JavaScript，没有构建步骤或外部运行时依赖。

## 首版功能

- 记录日期、地图、模式、英雄、位置、攻守方、结果、段位和对局时长
- 选填消灭、助攻、阵亡、伤害、治疗和减伤数据，并可回头编辑
- 用筛选和搜索查看胜负、复盘状态、英雄和地图
- 记录本场亮点、最想改进的决策，以及下一局的具体执行点
- 建立带回放时间、事件类型、事实、当时判断、可避免性和替代动作的复盘条目
- 保存游戏内回放码和外部视频链接
- 设置一个训练目标，并逐场标记是否做到
- 按英雄和地图查看胜率、复盘完成率、每 10 分钟阵亡和已填写战绩均值
- 在浏览器本地保存、导入和导出 JSON 备份
- 桌面与手机布局

## 开源与部署

本项目使用 MIT License，欢迎查看、修改和提交改进。仓库计划公开发布在项目所有者的 GitHub 账号上。推送到 `main` 后，仓库内的 GitHub Pages workflow 可发布静态网站；首次发布需要在仓库设置中启用 GitHub Actions 作为 Pages 来源。

不要提交 `.env`、账号凭据、真实玩家记录、私人回放视频或分享令牌。

## 当前边界

数据由玩家手动填写，网站不会读取游戏客户端或自动抓取战绩。当前版本没有登录、云端存储或跨设备同步，因此清除浏览器网站数据前请先导出备份。回放码可以复制到游戏内查看；网页本身不播放游戏回放。项目以“私人训练记录”为默认方向，不提供公开排行榜。
